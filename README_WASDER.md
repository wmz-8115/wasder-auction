# 蛙士得（WASDER）

蛙士得是一个运行在 Monad Testnet 上的轻量级链上拍卖实验项目。它把“发布拍品、公开竞价、倒计时延长、结算和余额提取”做成一个可以直接用 MetaMask 体验的网页流程。

## 我们在做什么

蛙士得不是传统中心化拍卖后台，而是把核心拍卖规则放进智能合约：

- 拍品和竞价状态由 Monad 测试网记录；
- 用户使用自己的 MetaMask 钱包参与，不需要 ChatGPT 注册；
- 每笔有效报价都会公开更新当前最高价和领先者；
- 创建拍卖后有 3 分钟首拍窗口；
- 每次有效出价后，拍卖倒计时重置为 60 秒；
- 被超过的报价进入可提取余额，用户可以主动提取；
- 到期后可由前端触发结算。

## 主要功能

### 拍卖大厅

从合约读取所有拍卖，显示拍品图片、起拍价或当前最高价、拍卖状态和剩余时间。页面会定时刷新链上数据。

### 发布拍品

连接 MetaMask 后填写标题、描述、分类、起拍价和固定加价比例。图片网址可以留空，前端会从内置奶蛙素材中随机选择一张，并将图片地址写入该拍品元数据。

### 参与竞价

前端会在提交钱包前检查最低报价、卖家身份、当前领先者和拍卖是否已结束；之后由 MetaMask 发起真实 Monad Testnet 交易。

### 结算与提取

拍卖到期后可以触发结算。被超过的报价退款和卖家成交款进入合约中的可提取余额，用户通过 `withdraw` 提取到自己的钱包。

## 技术架构

- React + TypeScript + Vite
- Viem：连接 MetaMask、读取合约和发送交易
- Solidity：FlashAuction 拍卖合约
- Monad Testnet：链上执行环境
- 静态前端部署：Sites 临时域名

## 用户操作流程

1. 打开前端并安装 MetaMask。
2. 将网络切换到 Monad Testnet（Chain ID 10143）。
3. 使用水龙头获取测试 MON。
4. 点击“连接 MetaMask”。
5. 发布拍品或打开已有拍品。
6. 输入不低于最低报价的金额，在 MetaMask 中确认交易。
7. 等待链上确认，页面会自动读取最新状态。
8. 拍卖结束后触发结算，并在余额中心提取资金。

## 项目边界与后续工作

这是一个黑客松/测试网版本，当前重点是验证链上拍卖闭环。正式上线前仍需要：

- 审计合约和完善取消、超时、异常交易处理；
- 使用正式域名和稳定的图片/元数据存储；
- 为奶蛙形象、图片和音效取得明确授权；
- 增加更完善的账户切换、链上区块时间同步和交易链接；
- 接入真实的素材上传和内容管理后台。
